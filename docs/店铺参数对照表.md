## 二、接单 SOP（对应本系统流程）

1. 客户下单 → 闲鱼自动回复设置："请发原图（越清晰越好），确认档位和风格"
2. 收到原图 → 本系统 Web 面板上传 → 选档位/风格/规格 → 生成
3. 出图 → 先发"成品预览.png"给客户确认 → 满意后发施工图+清单
4. 交付 → 发 zip 链接或逐张发图 → 闲鱼点发货
5. 3 天后跟进："拼出来了吗？方便返个图吗？"（返图=免费内容素材）

## 三、内容引流（对应 content 模块）
- 每单自动产出：对比图 + 3 条文案 → 直接发小红书
- 小红书标题公式（来自原文）：
  - "我好像发现了一个很赚钱的副业……"
  - "把{主题}做成拼豆送给她，她哭了"
  - "10 秒生成拼豆图纸，AI 真的太强了"

## 四、自动化进阶（阶段二-四）
- **阶段二**：watch.py 监听网盘同步目录 → 丢图自动出图；素材包（节日/动漫主题）自动发货 ¥9.9
- **阶段三**：Web 面板公网化（内网穿透/云主机）→ 客户自助上传选档支付，替代人工接单
- **阶段四**：采购清单联动淘宝/拼多多搜索链接（CPS 返佣）→ "图纸便宜/免费、材料返佣"

## 五、反馈学习闭环（运营提效）

1. 交付后 3 天跟进客户："拼出来了吗？方便返个图吗？"（返图=素材，反馈=经验）
2. 不满意订单 → Web 面板记录：原因 + 调整动作 + 经验教训
3. 下次同类订单自动弹"历史经验提醒"（如该风格常被反馈颜色偏淡）
4. 积累后形成自己的"避坑手册"，同类问题不再踩坑，交付质量持续上升
5. 经验库统计可反哺选品：哪个风格不满意率高 → 调整或下架；哪个高满意 → 加推

## 六、差异化卖点（对客户话术）

3. "先看成品预览再下单，不满意随时改"（S6 预览）
