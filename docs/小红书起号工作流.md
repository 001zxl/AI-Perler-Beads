# 小红书拼豆账号起号工作流（口碑 + 粉丝 → 卖图纸转化）

## 〇、总纲：起号是手段，卖图纸是目的

**每条内容都要同时完成两件事**：
1. 让用户觉得"图纸好看、我也想拼"（种草）
2. 让用户记住"这家图纸跟别人不一样"（差异化认知）

**我们的 6 大差异化卖点（内容弹药，反复植入）**：

| # | 卖点 | 一句话表达 | 用户为什么在乎 |
|---|---|---|---|
| 1 | **色卡映射** | "色号对应你买得到的豆子" | 别人的图颜色对不上材料，拼一半翻车 |
| 2 | **采购清单** | "自带清单，按色号直接买豆" | 不用自己数豆子、猜颜色 |
| 3 | **AI 质检** | "每张图纸都验过，保证能拼出来" | 花 20 块买到不能拼的图=白花钱 |
| 4 | **19 种风格** | "一张照片 19 种风格任选" | 别人只有一种，我有选择权 |
| 5 | **坐标+色号** | "照着坐标拼，新手不迷路" | 新手最怕拼错位置 |
| 6 | **10 分钟出图** | "加急 1 小时交付" | 定制不用等好几天 |

**转化路径（内容 → 钱）**：
```
小红书笔记（种草+差异化认知）
  → 评论/私信询单（"怎么定制""多少钱"）
  → 引导到 闲鱼/小红书商城 下单（引流款 4.2 元入门）
  → 老客户复购（次数包 29 元/10次）/ 会员（39 元/月）
  → 回头客 + 口碑裂变
```

**注意**：起号期（前 2 周）不硬转化，先立信任；内容里埋"差异化钩子"，等用户主动问，再自然引导。

## 一、定位

**账号人设**：拼豆图纸设计师（AI 辅助）——"会画图纸、懂拼豆、爱分享、图纸靠谱"
**30 天目标**：500-1000 真实粉丝 + 高收藏口碑 + 建立"这家图纸靠谱"的认知
**长期目标**：粉丝 → 询单 → 图纸订单（引流款 4.2 起）

## 二、内容矩阵（5 类，每类都植入差异化）

| 类型 | 占比 | 差异化植入点 | 转化钩子 |
|---|---|---|---|
| ① 图纸展示类 | 40% | 施工图+色号+清单截图（卖点2/5） | "想要同款评论区扣1"（低频） |
| ② 教程教学类 | 25% | 教"选图纸"时强调"色号对得上材料"（卖点1） | 教程结尾"不会选可以问我" |
| ③ 过程展示类 | 15% | AI出图→拼制→成品（卖点6 效率） | "AI 出的图拼出来长这样" |
| ④ 热点蹭流类 | 15% | 热点图纸+19风格（卖点4） | 蹭角色流量顺带展示能力 |
| ⑤ 互动/日常类 | 5% | 人设+答疑 | 评论区答疑建立专业信任 |

## 三、选题策略（结合转化）

**起号期（前 2 周）**——确定性内容为主：
1. **宠物定制**（流量最大）：猫狗照片→图纸，天然展示"来图定制"能力
2. **教程**（收藏高）："怎么把照片变成拼豆图纸"——搜的人=潜在客户
3. **情侣/头像**（收藏高）：展示定制场景

**3 周起**——追热点：
- 新角色 3 天内出图（热点雷达自动）
- 节日提前 1 周备
- 版权敏感 IP 只蹭不做

**选题验证 3 秒法**：搜关键词 → 10+ 篇=需求真实；前排收藏>500=有爆款潜力。

## 四、标题公式（5 套，带转化钩子）

1. **结果展示型**："[主题]拼豆图纸 来了！[差异亮点]"
   → "吉伊卡哇拼豆图纸 来了！色号对得上材料那种"
2. **教程教学型**："手把手教你 [目标]"
   → "手把手教你 10 分钟把照片变成拼豆图纸"
3. **反差对比型**："[素材] → [成品]，[感叹]"
   → "一张照片 → 能拼出来的图纸，效果太治愈了"
4. **热点借势型**："最近超火的 [角色]，[行动]"
   → "最近超火的 [新番角色]，连夜做了拼豆图纸"
5. **互动提问型**："[疑问]？[引导]"
   → "拼豆新手最怕图纸拼不出来？评论区聊聊"

## 五、封面与配图（差异化可视化）

- **封面**：成品预览 + 大标题 + 差异化角标（"带色号" / "附清单" / "19种风格"）
- **配图 3-5 张**：封面 → 施工图(坐标色号) → 色卡清单 → 成品预览 → 过程对比
- 第 2/3 张就是差异化证据（别人没有的施工图+清单）

## 六、文案（起号版，植入差异化 + 轻钩子）

模板示例（图纸展示类）：
"最近被 [角色] 可爱到了💛 连夜做了拼豆图纸！
图纸自带坐标+色号+采购清单，色号对应能买到的豆子，照着拼就行✨
做了 [N] 种风格：[风格列表]
想要同款/来图定制（宠物/情侣/全家福）可以私我"

**安全红线**：低频用"私我/扣1"；不含"微信/闲鱼/加V"；不主动营销。

## 七、转化 SOP（询单→订单）

1. 评论区有人问"怎么定制" → 回复"私你啦，发我照片就行"（引导私信）
2. 私信收图 → 报价（引流款 4.2 起，按档位）→ 收款（微信/支付宝）
3. 系统生成（10 分钟）→ 发预览确认 → 交付
4. 满意客户 → 推"次数包"（29 元/10次）→ 复购
5. 每周记录转化数据：询单数/成交数/客单价
