## 手动发布步骤（App，约 1 分钟/条）

1. 打开小红书 App → 底部"+" → 选"图文"
2. 从相册选图（先把 xhs_posts 里的图片 AirDrop/微信传到手机）：
   - 顺序: 封面 → 施工图 → 色卡统计（3 张）
3. 填标题（文案.txt 里第一段截前 20 字）：
   - 吉伊卡哇: "吉伊卡哇拼豆图纸 来了！"
   - 薇斯纳: "原神新角色薇斯纳 拼豆图纸"
4. 正文: 粘贴文案.txt 内容
5. 标签: 粘贴标签.txt（或 App 内搜索添加）
6. 点"发布"

## 安全建议（重要）
- 每天最多 1 条，别连续发
- 发布时间: 工作日 12:30 / 18:30，周末 10:30 / 20:30（错开）
- 文案里"私信""微信""闲鱼"这些词尽量少用，避免被判营销引流
- 有人评论再引导，别主动私信营销
- 发完 2-3 条后，正常浏览/点赞/评论别人的内容（养号行为）降低风险

## 素材怎么传到手机
- 方式1: AirDrop（Mac → iPhone 最快）
- 方式2: 微信"文件传输助手" → 手机保存
- 方式3: 如果登录了小红书 MCP，我可以直接帮你把图放进 App 草稿
