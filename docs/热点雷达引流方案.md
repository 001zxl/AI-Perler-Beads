# 热点雷达 + 素材工场 + 引流引擎（思路方案）

> 你的想法：实时获取每日最新的电视剧/动漫/电影画面 → 放到我们 Web 上 → 有人想生成时我们动作快 + 引流宣传
> 我的升级：**不是"展示画面的图库"，而是"热点 → 图纸"的自动生产流水线**

## 一、为什么有搞头（价值验证）

1. **需求真实存在**：拼豆核心人群是动漫/影视粉（宝可梦、吉伊卡哇、原神），"我染上了拼豆"话题 61.5 亿浏览。"最近火的那个角色"是搜索量最高的词。
2. **抢搜索先机**：热点角色出现 → 3 天内全网都在搜"XX 拼豆图纸"→ 你提前预制了图纸 → 闲鱼/淘宝/小红书搜索第一屏就是你。**热点 = 免费流量入口**。
3. **内容不断更**：热点图纸库 = 每天都有新素材发小红书/抖音 → 解决"日更内容从哪来"的运营难题。
4. **交付提速**：客户要"最近火的 XX"→ 图纸库已有 → 10 分钟交付，不用等 AI 现做。

## 二、整体架构（三合一）

```
┌─ 热点雷达 ─────────────────────────────┐
│ DailyHotApi(自建, 聚合微博/抖音/B站/小红书/知乎) │
│ 每日定时抓取 → 热点词 + 热度值                  │
│  ↓ AI 过滤（动漫/影视/角色类才保留）             │
└──────────────┬─────────────────────┘
               ▼
┌─ 素材工场 ─────────────────────────────┐
│ 热点角色 → 找参考图（封面图/官方图/同人图）       │
│  ↓ 我们现有管线 S1（image edit 以原图为底）       │
│ AI 像素化+风格化（保留原角色特征！不搬运原图）      │
│  ↓ S2-S9                                    │
│ 批量生成"热点图纸包"（多风格可选）                │
└──────────────┬─────────────────────┘
               ▼
┌─ 引流引擎 ─────────────────────────────┐
│ Web 新增"本周热点图纸"板块（图纸+成品预览展示）    │
│ 一键生成小红书/抖音素材（对比图+文案）             │
│ 客户搜"XX图纸"→ 看到你的 → 下单（现成图纸秒交付）  │
└──────────────────────────────────────┘
```

## 三、关键设计决策（已按你的要求确认）

### 1. 多平台热榜：DailyHotApi 自建 ✅
- 开源项目 `imsyy/DailyHotApi`（4000+ star），**聚合微博热搜/抖音热榜/B站热门/小红书/知乎**等
- 部署方式：Docker 一键 或 Vercel 免费托管，数据每日/每小时刷新
- 已实测：B站热门 API 直接可用（含标题/分区/封面图 URL）
- 说明：小红书热榜需确认该库支持版本（部分平台接口会变动，需定期维护）

### 2. 素材方式：参考图驱动 + AI 重绘（不搬运、不脱离）✅
你的要求："不直接搬运，但不能脱离原有素材" —— 完全可行，**这正是我们管线的天然优势**：
- 取参考图：B站封面图 / 官方角色图 / 百科图（作为"参考底图"）
- **S1 用 image edit 模式**：以参考图为底 → AI 转拼豆像素风 → **保留原角色特征**（脸型/配色/标志物），但不是原图搬运
- 产出 = 你的特色"热点角色拼豆图纸"，既规避版权风险，又是差异化卖点
- ⚠️ 边界：真人剧照/明星肖像**不做**（肖像权风险高）；动漫/卡通角色做像素二创（国内同人生态普遍接受）

### 3. 展示与版权
- Web 展示**图纸成品**（像素化后已是二创作品），不直接挂原剧照
- 商品标题带角色名（蹭搜索），详情写"原创像素设计"（同人二创属性）

## 四、引流打法（把热点变成钱）

1. **Web 新增"本周热点图纸"板块**：每日更新 3-5 个热点角色图纸 + 成品预览，页面即"热点橱窗"
2. **小红书/抖音自动化内容**：热点图纸 → 自动生成"XX角色拼豆图纸来了"对比图+文案 → 每天 1-2 条
3. **搜索截流**：角色火的时候，闲鱼商品标题立刻上"XX 拼豆图纸定制"→ 吃搜索流量
4. **预售玩法**：热点刚起来时（图纸还没人做）挂"预售，24小时出图"→ 你 10 分钟出 → 交付碾压
5. **系列化**：一个爆火角色 → 出"经典/Q版/8-bit/霓虹"多风格 → 一鱼多吃

## 五、落地步骤（分两期）

### 一期：热点雷达 + 图纸库（本周可完成）
1. 部署 DailyHotApi（Docker/Vercel），配置定时抓取（每日 3 次：早/午/晚）
2. 新增 `app/hotspot.py`：抓热榜 → AI 过滤动漫/影视类 → 按热度排序 → 存热点库
3. 新增 `app/hot_batch.py`：热点角色 → 自动找参考图 → 批量调现有管线出图（多风格）
4. Web 新增"本周热点图纸"板块（热点榜 + 图纸画廊 + 一键生成同款）
5. 每日定时任务自动跑（crontab / watch 模式）

### 二期：引流自动化（下月）
6. 小红书/抖音内容自动生成（热点图纸 → 素材包 → 排队发布）
7. 客户自助"热点图纸库"下单（现成图纸秒交付，不用等）
8. 热榜回流：热点图纸被大量搜索 → 反哺热榜权重 → 正向循环

## 六、风险与对策

| 风险 | 对策 |
|---|---|
| 版权投诉（角色图） | 只做像素二创（非原图搬运）；动漫角色为主，真人/剧照不做；收到投诉下架该 SKU |
| 平台接口变动（热榜） | DailyHotApi 定期更新；多源降级（B站 API 保底） |
| 热点判断不准（AI 过滤漏/错） | 人工审核环节：每天 5 分钟确认热点清单（"人工确认比全自动可靠"） |
| 图纸质量参差 | 复用现有质检闭环（S8），不合格自动重跑 |
| 引流过度被限流 | 小红书每天 1-2 条真实感内容，不刷屏 |

## 七、一句话总结

> **热点是流量，图纸是产品，我们的管线把两者自动焊死：热点一火，图纸立刻上架，客户一搜就有，一单 10 分钟。别人追热点靠手速，你靠系统。**
