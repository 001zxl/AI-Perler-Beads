# 🧩 拼豆工坊（beads-system）

**AI 拼豆图纸自动生成体系**：上传一张图 → 选档位/风格/规格 → 一键生成可施工交付包。
AI 负责"理解图片+像素化+风格化"，代码负责"网格+坐标+色号+用量+采购清单"——质量 100% 精确可控。

## 快速开始

### 1. 安装依赖（一次性）
```bash
python3 -m pip install fastapi uvicorn python-multipart   # Web 面板
# PIL / numpy 若缺失：
python3 -m pip install Pillow numpy
```

### 2. 启动 Web 面板
```bash
cd beads-system
python3 -m uvicorn app.main:app --host 127.0.0.1 --port 8741
# 浏览器打开 http://127.0.0.1:8741
```

### 3. 或用 CLI 一键生成
```bash
python3 -m app.cli --input photo.jpg --tier 主力款 --style chibi_pastel --qc
python3 -m app.cli --input photo.jpg --tier 引流款 --style mono --colors 8
python3 -m app.cli --input photo.jpg --tier 利润款 --style retro8bit --width 60 --qc
```

### 4. 或监听文件夹自动出图（后期自动化）
```bash
python3 -m app.watch --dir orders/inbox --tier 主力款 --style classic
# 往 orders/inbox 丢图片，自动生成交付包
```

## 架构

```
上传图 → S1 AI像素化(bl qwen-image, 风格注入)
       → S2 网格量化(PIL, 自适应宽高比, 主体裁剪)
       → S3 色卡映射(ΔE2000, 风格色板加权)
       → S4 施工图渲染(自适应对比: 深底白线/浅底黑线)
       → S5 统计+CSV(+5%备用)
       → S6 成品预览(圆润豆粒+熨烫效果)
       → S7 小红书素材(对比图+文案)
       → S8 AI质检(检查AI输出; mono/minimal为代码兜底跳过)
       → S9 zip 打包归档
```

**设计要点**：质检检查 AI 像素底图（AI 会翻车的地方），不检查代码生成物（确定性正确）。

## 图纸质量（已升级，借鉴 Zippland/perler-beads）

| 改进点 | 旧方案 | 新方案（已生效） |
|---|---|---|
| 像素化 | LANCZOS 均值池化（模糊毛边） | **主导色提取**（每格取频率最高色，消除灰色毛边） |
| 色距 | CIEDE2000 | **Oklab 感知色距**（更符合人眼） |
| 杂色 | 无 | **BFS 连通区域合并**（清理孤立杂色块） |
| 色数控制 | 直接量化 | 主导色 → **全局量化到 N 色** → BFS |
| 成品预览 | 720×720（模糊） | **1440×1440**（+100% 分辨率，清晰度 +47%） |
| 施工图 | 40px/格 | **56px/格**（更大网格更清晰） |
| 色号可读性 | 深色格对比不足 | **8 向描边 halo**（任何底色可读） |

实测（视觉模型评分）：网格清晰度 10/10、整体专业度 7.5/10（深色格白字+描边已修复）

## 已知局限

- 通用图像模型（qwen-image）对某些风格（如严格黑白线稿）画不好 → mono 用代码灰度化兜底
- 施工图色号需匹配真实品牌色卡：初始色卡为常用色整理版，正式商用建议替换为官方色卡数据
- 质检（qwen3-vl-plus）对深色图纸/小字可能误判 → 已改为检查 AI 输出而非施工图
- 单张耗时约 30s-3min（取决于档位和是否质检）

## 反馈学习闭环（越用越聪明）

每个订单可记录客户反馈（满意/不满意+原因+调试动作+经验教训），
新订单生成时**自动检索相似历史经验**并带出建议：

- **记录**：Web 面板结果页下方"客户反馈记录"表单，或 API `POST /api/feedback`
- **沉淀**：经验存 `feedback.json`，按 风格/档位/主题/色卡 打标签
- **应用**：生成时自动匹配同类案例 → 结果里显示"历史经验提醒"（如"橘猫毛色 chibi_pastel 偏淡，建议加强饱和度"）
- **统计**：`GET /api/feedback` 查看不满意率、原因分布、风格分布

**使用建议**：每单交付后 3 天跟进客户（返图/反馈），把"不满意原因+你的调整+教训"录进去，
积累 20-30 条后，常见问题（颜色偏淡、风格不像、细节丢失）会自动变成生成时的预警提示。

### 风格健康度（自动评级）

经验库达到样本量后，系统按不满意率自动给每个风格评级并在前端标记：

| 级别 | 条件 | 前端表现 |
|---|---|---|
| 👍 好评 | 不满意率 < 25% | 绿色徽章，正常推荐 |
| 需谨慎 | 25% - 50% | 黄色徽章，弱化提示 |
| ⚠️ 降级推荐 | 不满意率 > 50% | 红色徽章 + 置灰 + 自动排到末尾 + 显示常反馈原因 |
| 样本不足 | < 2 条反馈 | 不评级（避免误判） |

用途：运营看板一眼识别"哪个风格坑客户"，及时调提示词或下架；客户自助模式下自动把差风格排后，降低退款率。

## 热点雷达 + 引流引擎（已实现）

### 每日自动化流水线
```
内置调度器（9/14/21点自动）→ 微博/B站热榜抓取 → AI 过滤动漫/影视/角色类
  → 热点批量出图（经典+Q版 2风格，保留角色特征）
  → 热点图纸画廊（Web 展示）→ 引流内容包（标题+文案+对比图）
  → daily_report.json 汇总
```

### Web 新增"本周热点图纸"板块
- **热点榜**：每日更新动漫/影视/角色类热点（来源+热度+AI 识别角色名）
- **一键出图**：点"出图"立即为热点角色生成图纸
- **批量出图**：一键为前 N 个热点全部出图
- **图纸画廊**：已生成的热点图纸（多风格 + zip 下载）

### 关键模块
| 模块 | 功能 |
|---|---|
| `app/hotspot.py` | 微博热搜+B站热门抓取、AI 过滤、热点库 |
| `app/hot_batch.py` | 热点→参考图(B站搜索)→批量出图→画廊 |
| `app/hot_content.py` | 引流内容包（标题+文案+对比图） |
| `app/run_daily.py` | 每日自动化任务（可手动运行） |
| 内置调度器 | 每天 9/14/21 点自动执行（无需 crontab） |

### 热点分类（新）
- AI 过滤时自动给热点分类：动画 / 游戏 / 影视 / 角色IP / 表情包 / 其他
- Web 面板顶部分类 tab 筛选，每个热点带分类徽章
- 受限源（如小红书签名失效）可用"手动添加热点"补充：输入词+角色+分类

### 闲鱼发布物料（新）
- Web 画廊每条热点带"🐟 导出闲鱼物料"按钮
- 自动生成: 闲鱼标题(5段式) + 描述(卖点/规格/三档价/话术) + 商品图 + 施工图 + 交付包 + goofish-cli 发布命令
- 输出到 `xianyu_posts/<角色>/`，可手动复制发布或配合 goofish-cli 半自动发布
- goofish-cli 需要 Python 3.11+ 环境和用户 cookie（`goofish auth login`）
